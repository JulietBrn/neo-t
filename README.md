# Front-End Developer Interview Task: Landing Page Implementation

This project is a landing page created for the Front-End Developer interview task. It includes a responsive, interactive design with smooth animations and optimized performance. The landing page showcases a rotating slider, a three-step process section, animated cards, and a strong call-to-action (CTA) for registration.


## Deploy

You can view the live version at the following link: [**Site**](https://julietbrn.github.io/neo-t/public/).

## Features

### 1. Layout & Design:
- **Rotating Slider/Carousel:** The top section features a rotating slider that showcases the welcome offer with smooth transitions between slides.
- **Three-Step Process Section:** Below the slider, a three-step animation guides users through the process: **Register**, **Deposit**, **Play**.
- **Animated Cards Section:** Three animated cards representing **Slots**, **Live Games**, and **Excellent Service** with engaging hover effects.
- **CTA:** A strong **Register** Call-to-Action at the bottom of the page, encouraging users to take the next step.
- **Responsiveness:** Fully responsive across all devices, optimized down to **320px** wide screens.
- **Cross-Browser Compatibility:** Ensured compatibility with modern browsers.

### 2. Animations & Interactivity:
- **Smooth Transitions:** The rotating slider smoothly transitions between slides, enhancing the user experience.
- **Step-by-Step Animations:** The three-step section uses animation to visually guide the user through the registration process.
- **Card Hover Effects:** The animated cards have engaging hover effects that draw attention to key services.
- **Background Animations:** Subtle animated elements in the background to enhance the experience without distracting from the main conversion goal.

### 3. Code Quality:
- **Clean & Maintainable Code:** The code is well-structured, following best practices for clarity and maintainability.
- **Semantic HTML:** Proper use of semantic HTML tags such as `<h1>`, `<h2>`, `<main>`, and `<section>` to ensure accessibility and SEO friendliness.
- **CSS/SCSS for Styling:** SCSS was used to manage styles in a modular and organized manner, ensuring reusability and maintainability.
- **Vanilla JavaScript:** Interactive elements are powered by plain JavaScript for smooth user interaction.

### 4. Performance & Optimization:
- **Fast Loading Times:** Optimized images (using **webp** format) and assets to ensure fast loading times.
- **SEO Best Practices:** The page includes proper meta tags (title and description) in the head, with a well-structured heading hierarchy.
- **W3C Validation:** The HTML structure has been validated using the [W3C Validator](https://validator.w3.org/nu/).

### 5. Bonus Points:
- **Well-Commented Code:** Key sections and logic are explained through comments in the code for better understanding.
- **CSS Animations:** CSS keyframes are used for most animations, reducing reliance on JavaScript and enhancing performance.
- **Lazy Loading:** Implemented lazy loading for images and assets to improve page load time.
- **Favicon:** A favicon has been added for a more polished look.
